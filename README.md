# 💼 Financial Advisory CRM

**A custom web platform for financial advisors, recruiters and head-office teams: leads, clients, recruiting, compliance and planning tools in one place.**

*A [QllmSoft](https://qllmsoft.com) client project · Type: Custom Financial Advisory CRM*

---

## 📖 Overview

Financial advisory firms often juggle separate tools for prospecting, client servicing, hiring, compliance and portfolio analysis. Data gets duplicated, follow-ups are missed, and management has little visibility.

This platform replaces that patchwork with one secure, role-based system. Advisors manage leads and clients, recruiters run candidate pipelines, and head office tracks performance, approvals and compliance. Built-in calculators and market-data analytics support every planning conversation.

## ✨ Key Features

- 📈 **Lead Pipeline & Prospecting**: pipeline stages, appointment calendar, calls, tasks, opportunities and do-not-call management, with Excel and PDF export.
- 🤝 **Client Servicing**: KYC, portfolio analysis, portfolio strategy, communication sheets and weekly performance import.
- 🧑‍💼 **Recruiting**: secure candidate invites with automatic reminders, CV and signature capture with OCR, personality-test emails, recruiting events and an insights dashboard.
- 📊 **Funds & Stock Analytics**: live market prices and returns, portfolio optimisation and AI-assisted insights.
- 🧮 **Planning Calculators**: retirement simulation, RRSP, mortgage, real estate, loan repayment and life insurance.
- 💰 **Finance & Reporting**: income and expense tracking, rankings, performance trends and client-stage reports.
- 🔐 **Roles & Access Control**: per-user rights and organisation-hierarchy data visibility.
- 🔑 **Flexible Sign-in**: email login, Google, Facebook, Microsoft, and email or SMS one-time codes.
- 💳 **Subscriptions & Billing**: plans and online payments.
- 🌍 **Bilingual**: English and French, including client templates.
- ⏱️ **Automation**: scheduled daily digests of appointments and tasks.

## 🧰 Built With

C#, .NET Framework 4.6.2, ASP.NET MVC · Entity Framework · SQL Server · Azure cloud services · Responsive Bootstrap UI · PayPal Integration
